# ALTIV DEV roadmap

## V0.2 Foundation
- Chat + live preview shell
- Agent task classifier and execution pipeline
- Multi-model routing layer
- Project-isolated memory model
- GitHub/Vercel/Supabase capability map
- Responsive desktop/mobile interface

## V0.3 Connected agent
- Vercel AI Gateway streaming chat
- ToolLoopAgent with file, search and repo tools
- Supabase Auth + project persistence
- pgvector semantic memory
- GitHub import, commit, branch and PR actions

## V0.4 Runtime
- Isolated sandbox per project
- Dependency install/build/test
- Live preview URL
- Diff viewer and rollback
- Automatic compile-error repair loop

## V0.5 Browser QA
- Chrome DevTools MCP bridge
- Console/network/performance inspection
- Screenshot-based visual QA
- Mobile/desktop regression checks

## V1.0 Builder
- Create project from natural language
- Import existing GitHub project
- Autonomous edit/test/fix loop
- One-click preview and Vercel deploy
- Version history and restore
- Project/team memory
- Usage/cost observability
