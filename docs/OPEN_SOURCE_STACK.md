# Public-project reference stack

ALTIV DEV should integrate concepts selectively and respect every upstream license.

- vercel/ai — unified AI SDK, agents, streaming, tools.
- mem0ai/mem0 — long-term memory concepts; ALTIV can use pgvector/Supabase as its default store.
- browser-use/browser-use — browser-agent concepts for validation and autonomous testing.
- ChromeDevTools/chrome-devtools-mcp — DevTools/console/network inspection concepts.
- OpenHands ecosystem — coding-agent planning/execution patterns.
- Open Lovable projects — prompt-to-site, sandbox and preview patterns.
- bolt.diy ecosystem — multi-provider routing, workbench, preview and MCP patterns.
- E2B ecosystem — isolated code execution/sandbox concepts.

Rule: do not wholesale-copy repositories. Adopt APIs, patterns or compatible components after license and security review.
